# PhysiX — платформа с базой данных

Веб-сайт на казахском языке. Готовые страницы уроков, тестов, задач, лабораторных работ и приборов сохранены из исходного PhysiX.

## Запуск на Windows / macOS / Linux

1. Установите Python 3.10 или новее.
2. Распакуйте папку (архив), откройте терминал в папке `PhysiX_full_platform`.
3. Установите зависимости: `python -m pip install -r requirements.txt`.
4. Запустите: `python app.py`.
5. Откройте `http://127.0.0.1:5000` в браузере. **Не открывайте `static/index.html` двойным нажатием: он требует сервер.**

База создаётся автоматически: `instance/physix.db`.

## Как показать преподавателю

1. «Тіркелу» → зарегистрируйте куратора (ФИО, email, пароль, роль `Куратор`). После регистрации **обязательно войдите** через «Кіру» по email и паролю.
2. Откройте профиль куратора, скопируйте 8-символьный код группы. Выйдите.
3. «Тіркелу» → зарегистрируйте ученика с **другим** email, установите пароль, вставьте код куратора. Затем **войдите** как ученик.
4. Пройдите урок, сохраните тест. Выйдите.
5. Войдите как куратор по его email+паролю. В панели появится реальный ученик с прогрессом, тестами и лабораторными.
6. Выйдите и снова войдите как ученик — прогресс восстановится из SQLite.

Можно зарегистрировать любое число учеников и кураторов. Каждый куратор видит **только своих учеников**, привязанных по коду группы. В панели есть демо-ученики (для презентации), экспорт CSV и заметки, сохраняемые в БД. Ученик может присоединиться к куратору позже через кнопку профиля в шапке.

## Важно о размещении в интернете

Для работы учеников с разных компьютеров нужно разместить `app.py` и папку `static` **на сервере, доступном всем**, используя HTTPS. Если просто залить HTML на GitHub Pages, база и API работать не будут. SQLite требует постоянного диска и бэкапов; для большого числа пользователей лучше PostgreSQL.

Для реального учебного заведения понадобятся: проверка полномочий кураторов (сейчас каждый может выбрать эту роль при регистрации), почтовое подтверждение, сброс паролей, защита от перебора входа, HTTPS, резервное копирование, аудит и политика обработки персональных данных. Прогресс тестов сейчас рассчитывается в браузере и не защищён от намеренной подмены — для официальных оценок проверять ответы надо на сервере.

Старые браузерные профили из demo-html в базу **автоматически не переносятся**, поскольку в демонстрационной версии они не были защищены паролем. Начинайте с новой регистрации.

## Автоматические тесты

После установки зависимостей: `python -m unittest tests.py`. Тесты создают временную тестовую базу, не изменяя основной `instance/physix.db`.

На Windows можно открыть `start_windows.bat`, он установит Flask и запустит сайт.
